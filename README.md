# Command Line Params
(arg 1 has to be the program)<br>
(example: ./BrainSharp.exe helloworld.bf --safe --allocate 7 --compile)<br>
--unsafe | -u<br>
disables bounds checks<br>
--safe | -s<br>
enables bounds checks<br>
--allocate x | -a x<br>
specific allocated bytes to brainfuck program<br>
--compile | -c<br>
compile brainfuck to .net app<br>
--execute | -e<br>
executes the brainfuck code in an interp<br>
--track | -t<br>
(interp only) logs the highest detected memory index<br>
useful for min/maxxing allocate<br>
